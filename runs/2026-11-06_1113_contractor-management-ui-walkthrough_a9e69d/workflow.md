# Orchestrator instructions

You direct the session to walk through the UI as a user and make sure that the process runs seemlessly.

For the colled session tell it:
Pretend you work in health and safety. 
You are bringing on a new contracting company onboard so create it from scratch and also make up some documents for them.
The application holds the functionlaity of how it should be built so click through it as if you are new to the application.
The new contractor has to have the general health and safety reviewed and then working at heights. 
Simulate the process of them not having enough documents, requesting those documents, receiving those documents, adding them to the system and reviewing them once again to completion. Do not just use the AI review use the AI review as a scafloding and then review it yourself.
Be critical of how the application functions and it's user freindliness and change the things that do not make sense or stop the user from assesing to completion. 
Make sure you not your walk through so that we understand what happened. 
If a change is drastic send it through to the supervisor.
